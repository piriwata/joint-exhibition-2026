# 小林聡一 生徒展 — ランディングページ

小林聡一のもとで油彩やペン画を学ぶ生徒たちによるグループ展の、静的ランディングページです。海外美術館の企画展ポスターをイメージしたタイポグラフィと、複数作品が重なるランダムコラージュを採用しています。

## 展覧会情報

| 項目 | 内容 |
| --- | --- |
| 展覧会名 | 小林聡一 生徒展 |
| 会期 | 2026年11月1日（日）〜11月7日（土） |
| 会場 | Galerie ESPACE LA PORTE |
| 会場サイト | <https://espacelaporte.net/> |

展覧会情報を変更する場合は、まず `index.html` のヒーローと `#info` セクションの両方を更新してください。ページタイトルおよび `meta description` にも会期・会場が含まれています。

## ローカルでの確認

Node.jsはJavaScriptの構文チェックにのみ使用します。ページ本体にビルド工程はありません。

```bash
# ローカルサーバーを起動
npm start

# http://localhost:4173 をブラウザーで開く
```

JavaScriptの構文チェックは次のコマンドで実行できます。

```bash
npm test
```

`index.html` を直接開いても表示できますが、実際の公開環境に近い確認を行うため、ローカルHTTPサーバーの利用を推奨します。

## ディレクトリ構成

```text
.
├── index.html              # ページ構造、コピー、展覧会情報
├── package.json            # ローカルサーバーと構文チェック用コマンド
└── assets
    ├── css
    │   └── style.css       # レイアウト、配色、レスポンシブ指定
    ├── images              # コラージュで使用する作品サンプル
    └── js
        └── main.js         # 作品のランダム選択と再シャッフル
```

## コラージュの仕組み

1. `assets/js/main.js` の `artworks` に、画像パスと作品名を登録します。
2. 初回表示時にリストをシャッフルし、重複なしで4点を選びます。
3. ヒーロー内の4つの画像スロットへ選択した作品を割り当てます。
4. 「NEW MIX」ボタンを押すと、別の組み合わせを再抽選します。

作品を追加する場合は画像を `assets/images/` に保存し、次の形式で `artworks` に追記してください。

```js
{ src: 'assets/images/example.jpg', title: '作品名' }
```

画像は縦横比が異なっていても `object-fit: cover` でトリミングされます。重要なモチーフが中央付近にある画像が適しています。代替テキストは登録した作品名から自動生成されます。

### 現在のサンプル画像について

現在の `assets/images/*.svg` は、フェルメールの代表作の構図と色彩をモチーフにした簡略化されたグラフィックです。実作品の複製画像ではありません。本番公開で実作品画像に置き換える場合は、提供元、美術館、ライセンス、クレジット表記の条件を確認し、公開可能なファイルをリポジトリ内へ保存してください。外部URLを直接参照せずローカルアセットとして配置することで、静的納品後も確実に表示できます。

## デザインとレスポンシブ対応

- 基本カラーは `assets/css/style.css` 冒頭のCSSカスタムプロパティで管理しています。
- 800px以下でヒーローと概要を1カラムへ切り替えます。
- 480px以下ではコラージュ、見出し、展覧会情報を小画面向けに再配置します。
- `prefers-reduced-motion` が有効な環境では、スクロールと画像切り替えのアニメーションを抑制します。
- Google Fontsを読み込んでいます。完全なオフライン納品が必要な場合はフォントファイルをローカルへ配置し、`@font-face` へ切り替えてください。

## 静的ホスティングへの公開

ビルドは不要です。リポジトリ直下の以下をそのまま公開ディレクトリへアップロードしてください。

- `index.html`
- `assets/`

GitHub Pages、Netlify、Cloudflare Pages、一般的なレンタルサーバーなどで配信できます。サブディレクトリへ配置する場合も、現在のアセット参照は相対パスのため追加設定は不要です。

### GitHub Pages

`.github/workflows/pages.yml` に自動公開ワークフローを用意しています。`main` ブランチへのpushごとにGitHub Pagesを有効化してサイトを公開し、**Actions → Deploy to GitHub Pages → Run workflow** から手動公開もできます。自動的に有効化できない場合は、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。

公開URL: <https://piriwata.github.io/joint-exhibition-2026/>

デプロイ状況と公開URLは、ワークフローの `deploy` ジョブでも確認できます。

## 変更時のチェックリスト

- [ ] 会期、曜日、会場名がヒーローと開催概要で一致している

## 実装上の注意

- フレームワークやバンドラーを導入していないため、依存パッケージのインストールは不要です。
- コラージュの画像スロット数を変更する場合は、`index.html` の `.art` 要素、CSSの配置指定、JavaScriptで選択する点数をあわせて変更してください。
- 作品名や出展者名など、公開前に確定する情報はセマンティックなHTMLとして `index.html` に追記し、画像内の文字だけに依存しないようにしてください。
